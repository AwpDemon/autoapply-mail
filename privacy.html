Privacy policy

Last updated: November 13, 2026

autoapply mail is a personal tool used only by its owner, with the owner's own Google account.

What it accesses

Read-only access to the owner's Gmail (gmail.readonly), used to find emails about the owner's own job applications.

How data is used and stored

  • Email data is processed and stored only on the owner's personal computer.
  • It is never sold, shared with third parties, or used for advertising.
  • The tool never sends, deletes or changes email.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
